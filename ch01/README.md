# ch01 - Variables, Types, and Operators

This chapter focuses on working with data in Python: storing values in variables, understanding basic data types, performing calculations, handling user input, and formatting output with f-strings.

The exercises also cover debugging and using arithmetic operations to solve small problems.

## Exercises

| File | Description |
|---|---|
| [ex01_character_card.py](ex01_character_card.py) | Store character stats using variables and display them with f-strings |
| [ex02_predict_math.py](ex02_predict_math.py) | Predict the results of arithmetic operations and string expressions |
| [ex03_damage.py](ex03_damage.py) | Calculate normal and critical damage using user input |
| [ex04_shop_bug.py](ex04_shop_bug.py) | Find and fix bugs in a shop calculator |
| [ex05_play_time.py](ex05_play_time.py) | Convert seconds into hours, minutes, and seconds |
| [ex06_scoreboard.py](ex06_scoreboard.py) | Format player scores and accuracy using f-string alignment |
| [ex07_coins.py](ex07_coins.py) | Convert copper coins into gold, silver, and copper |
| [ex08_debug_xp.py](ex08_debug_xp.py) | Inspect variables and expressions using the debugger |
| [ex09_level_curve.py](ex09_level_curve.py) | Calculate player levels and display an XP progress bar |

## Final Exercise

[Chapter 01 - Character Creator](ch01_exam/README.md)

For the final exercise, I created a small RPG character creator that calculates character stats based on the player's strength.

I also worked on making the terminal interface adjust to the length of the character's name and title instead of using a fixed width.

## Concepts Covered

- Variables and constants
- Basic data types: `int`, `float`, `str`, and `bool`
- Arithmetic operators and operator precedence
- Integer division (`//`) and modulo (`%`)
- Type conversion with `int()` and `float()`
- User input with `input()`
- String formatting and alignment with f-strings
- String multiplication and concatenation
- Debugging and inspecting variables

## Notes

Some exercises involve predicting the output of a program, fixing broken code, or completing missing parts.

Others are small programs written from instructions, using only the concepts covered so far.
