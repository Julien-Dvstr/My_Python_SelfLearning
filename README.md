# My_Python_SelfLearning

This repository is where I document my Python learning journey.

I'm using it to track my progress, practice what I learn, and keep a record of the concepts and exercises I've worked on.

## About

The goal of this project is to build a solid understanding of Python, starting with the basics and gradually moving toward more advanced concepts.

This repository also serves as part of my GitHub portfolio, showing my learning process and how my skills develop over time.

AI is used to create exercises and review my solutions, not to write the code for me.

## Progress

This is an ongoing personal learning project. I'll keep updating the repository as I work through new topics and exercises.

Each chapter focuses on different Python concepts, with exercises to practice what I've learned.

Some exercises use a small RPG or game theme to make them more interesting.

## Running the exercises

You'll need Python 3 installed to run the scripts.

Clone the repository:

```bash
git clone https://github.com/Julien-Dvstr/My_Python_SelfLearning.git
cd My_Python_SelfLearning
```

Run an exercise from the repository's root directory:

```bash
python ch01/ex09_level_curve.py
```

You can replace the file path with any other exercise you want to run.

## Notes

The exercises follow my learning progression, so I try to solve them using only the concepts I've covered so far.

Some solutions might not be the most efficient way to do things, but the goal is to understand how Python works before moving on to more advanced approaches.
