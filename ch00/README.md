# ch00 - Introduction
 
First chapter, just getting started: writing and running a script, reading error messages, and learning how Python executes code line by line.
 
## Exercises
 
| File | What it's about |
|---|---|
| `ex01_welcome.py` | First script, printing text to the console |
| `ex02_first_errors.py` | Fixing broken code by reading the error messages |
| `ex03_predict_order.py` | Guessing the output before running the code |
| `ex04_debugger.py` | Using the PyCharm debugger step by step |
| `ex07_title_screen.py` | A simple title screen for a text game |

#### [Ch00_Exam](ch00_exam/README.md) is the end-of-chapter test, a small project done without help, to check what I remember from this chapter before moving on to the next one.
